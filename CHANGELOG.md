# IntelliRevo Changelog

## [1.0.0]
### Added
- `.rv` file type with icon
- code insight through revo's lsp: syntax highlighting, hover, go to definition, find usages
- revo run configurations, with output in the Run window
- line comments with Ctrl+/
- creating `.rv` files (New > Revo File)
- setting to configure the path to the revo executable (Settings > Tools > Revo)
